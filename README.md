# ระบบปรับเอกสาร (บัณฑิตวิทยาลัย)

ศูนย์รวม (hub) จัดรูปแบบเอกสารที่ได้จากระบบต่าง ๆ ให้เป็นไฟล์ Word / PDF รูปแบบมาตรฐานพร้อมใช้งาน
เลือก **ประเภทเอกสาร** ด้านบนของหน้าโปรแกรม แล้ววางไฟล์ — ประเภทเอกสารเพิ่มได้ภายหลังโดยไม่ต้องแก้ตัวโปรแกรมหลัก
(วิธีเพิ่ม: [doctypes/README.md](doctypes/README.md))

| ประเภทเอกสาร | ทำอะไร |
|---|---|
| **บฑ.31 อาจารย์พิเศษ** | ปรับไฟล์ `Export (xx).doc` ที่ดาวน์โหลดจากระบบ (หนังสือเชิญ / หนังสือขออนุมัติอาจารย์พิเศษ ไทย/อังกฤษ) หรือสร้างหนังสือจาก PDF หน้า บฑ.31 (e-Form) ให้เป็นรูปแบบเดียวกับไฟล์ตัวอย่าง |
| **บฑกศ.39 ผู้ทำหน้าที่หัวข้อวิทยานิพนธ์** | ปรับไฟล์ .docx ที่ระบบสร้าง (หนังสือเชิญ / หนังสือขออนุมัติ ผู้ทำหน้าที่เพื่อให้ได้มาซึ่งหัวข้อวิทยานิพนธ์หรือการค้นคว้าอิสระ) — เลือกแท็บหนังสือเชิญหรือหนังสือขออนุมัติก่อนวางไฟล์ |

**ติดตั้งบนเครื่องใหม่ด้วยคำสั่งเดียว** — กด `Win + R` วางคำสั่งนี้แล้ว Enter (ดาวน์โหลดจาก GitHub + ติดตั้งให้เอง):

```
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/supawitmar/as-document/main/get.ps1 | iex"
```

| เอกสาร | สำหรับ |
|---|---|
| [INSTALL.md](INSTALL.md) | **ติดตั้งบนเครื่องอื่น** — ต้องมี Word + Python 3.9+ + ฟอนต์ TH Sarabun New/PSK (คู่มือมีลิงก์และขั้นตอนติดตั้งครบ) |
| [HANDOFF.md](HANDOFF.md) | ผู้ดูแล/พัฒนาต่อ — โครงสร้างระบบ กฎการจัดรูปแบบ ข้อจำกัด และจุดที่ต้องแก้บ่อย |
| [doctypes/README.md](doctypes/README.md) | เพิ่ม/สอนรูปแบบเอกสารประเภทใหม่ และปล่อยเป็น patch ให้เครื่องอื่น |

**อัปเดต:** เมื่อมีประเภทเอกสารใหม่หรือแก้รูปแบบ โปรแกรมจะแสดงแถบ "มีอัปเดตใหม่" — กด **อัปเดตเลย** ครั้งเดียว
| README.md (ไฟล์นี้) | วิธีใช้งาน |

## วิธีใช้

ดับเบิลคลิกไอคอน **"ระบบปรับเอกสาร"** บน Desktop โปรแกรมจะเปิดเป็นหน้าต่างแอป (ผ่าน Microsoft Edge)
แล้วเลือกการ์ด **ประเภทเอกสาร** ด้านบน (โปรแกรมจำประเภทที่ใช้ล่าสุด) — ด้านล่างนี้คือวิธีใช้ของ **บฑ.31 อาจารย์พิเศษ**

1. **ช่อง 1 หนังสือเชิญ**: ลากไฟล์ Export หนังสือเชิญมาวาง หรือกด "เลือกไฟล์"
2. **ช่อง 2 หนังสือขออนุมัติ**: ติ๊ก **"ต้องการหนังสือขออนุมัติ"** ก่อน (ถ้าไม่ติ๊ก ช่องนี้จะเป็นสีเทาและใช้ไม่ได้
   และไฟล์ในช่องนี้จะไม่ถูกแปลง) แล้วลากไฟล์มาวาง หรือกด "เลือกไฟล์" — โปรแกรมจำค่าที่ติ๊กไว้
3. กด **"ปรับเอกสาร"** → เสร็จแล้วกดปุ่ม **Word** / **PDF** ในแต่ละแถวเพื่อเปิดไฟล์

- รองรับทั้ง **ภาษาไทยและภาษาอังกฤษ** — ระบบรู้เองว่าหนังสือจะเป็นภาษาอะไร แล้วแสดงป้าย
  **"หนังสือภาษาไทย · บฑ.31"** (แดง) / **"หนังสือภาษาอังกฤษ · GR.31"** (น้ำเงิน) และชื่อไฟล์ที่จะได้ (→ …docx) ในแต่ละแถวก่อนกดแปลง
  - ไฟล์ Export: ดูจากถ้อยคำในหนังสือ (เรียน/เรื่อง/ขอแสดงความนับถือ/ที่ อว ↔ Dear/Sincerely/Ref.No/COURSE)
  - PDF บฑ.31: ตามช่อง "ภาษาที่ขอหนังสือเชิญ" ในแบบฟอร์ม
  - ถ้าตัดสินไม่ได้ (หรือแบบฟอร์มไม่ระบุภาษา) จะแจ้งและไม่แปลง แทนที่จะเดา
  - แผงสรุปด้านขวาแสดงจำนวนหนังสือแยกตามภาษาของรอบที่จะแปลง
- ปุ่ม "ไฟล์ใหม่ใน Downloads" (มุมขวาบน) ดึงไฟล์ Export ที่ดาวน์โหลดภายใน 3 วันและยังไม่เคยแปลง แล้วจัดลงช่องตามประเภทให้เอง
- ถ้าวางไฟล์ผิดช่อง จะมีแจ้งเตือนพร้อมปุ่ม "ย้ายไปช่อง…"
- ตัวเลือก (แผงขวา): สร้าง PDF, ที่บันทึกไฟล์ — ชื่อวิชาในหนังสือใช้ภาษาอังกฤษเสมอ
- ไฟล์ที่ "เลือกไฟล์" หรือดึงจาก Downloads จะบันทึกข้างไฟล์ต้นฉบับ ส่วนไฟล์ที่ลากมาวางในหน้าต่างจะบันทึกใน Downloads
- ลากไฟล์ไปวางบนไอคอนบน Desktop ก็ได้ โปรแกรมจะเปิดพร้อมไฟล์นั้น
- มีโหมดสว่าง/มืด (ปุ่มรูปพระจันทร์) ปิดหน้าต่างแล้วโปรแกรมหยุดทำงานเอง

ชื่อไฟล์ผลลัพธ์ (ทั้งจากไฟล์ Export และ PDF บฑ.31) — ชื่ออาจารย์พร้อมตำแหน่งทางวิชาการ (ตัดคำนำหน้า นาย/นาง/นางสาว และวุฒิท้ายชื่อ เช่น M.D.):

| ภาษา | หนังสือเชิญ | หนังสือขออนุมัติ |
|---|---|---|
| ไทย | `หนังสือเชิญ-บฑ.31 EGIT617 ผู้ช่วยศาสตราจารย์ ดร. สมชาย ใจดี.docx` | `หนังสือขออนุมัติ-บฑ.31 EGIT617 ผู้ช่วยศาสตราจารย์ ดร. สมชาย ใจดี.docx` |
| อังกฤษ | `หนังสือเชิญ-GR.31 SCFS522 Associate Professor Dr. Somchai Jaidee.docx` | `หนังสือขออนุมัติ-GR.31 SCFS522 Associate Professor Dr. Somchai Jaidee.docx` |

ถ้ามีไฟล์ชื่อซ้ำอยู่แล้ว จะต่อท้ายด้วย (2), (3) … ไม่เขียนทับ

บรรทัดคำสั่ง:

```bash
python fix_letters.py "Export (90).doc" "Export (91).doc" --pdf
```

| ตัวเลือก | ความหมาย |
|---|---|
| `-o DIR` | โฟลเดอร์ปลายทาง |
| `--pdf` | สร้าง PDF เพิ่ม |
| `--doc` | เก็บไฟล์ .doc (Word HTML) แบบเดียวกับไฟล์ตัวอย่างเพิ่ม |
| `--no-supervisor` | ไม่ต้องขออนุมัติผู้บังคับบัญชา (ตัดประโยคแจ้งผู้บังคับบัญชา) |

## ชื่อวิชาภาษาอังกฤษ

หนังสืออนุมัติจากระบบมีแต่ชื่อวิชาภาษาไทย แต่รูปแบบตัวอย่างใช้ชื่อภาษาอังกฤษ
โปรแกรมจะจำชื่อภาษาอังกฤษจากหนังสือเชิญไว้ใน `doctypes/bt31/data/courses.json` อัตโนมัติ
→ **แปลงหนังสือเชิญกับหนังสืออนุมัติพร้อมกัน** (หรือแปลงหนังสือเชิญก่อน) จะได้ชื่อภาษาอังกฤษเสมอ
หรือจะเพิ่มเองในไฟล์นั้นก็ได้

## สร้างหนังสือจาก PDF หน้า บฑ.31 (ไม่ต้องใช้ไฟล์ Export)

1. เปิดหน้า **บฑ.31 คำร้องขอเชิญอาจารย์พิเศษ** ในระบบฐานข้อมูลวิทยานิพนธ์/สารนิพนธ์ → กด Ctrl+P → บันทึกเป็น PDF
2. ในโปรแกรมเลือกแท็บ **"สร้างจาก PDF ระบบ บฑ.31 (e-Form)"** แล้วลากไฟล์ PDF มาวาง (หรือกด "เลือกไฟล์ PDF")
3. ติ๊ก **"สร้างหนังสือขออนุมัติด้วย"** ถ้าต้องการ (แบบฟอร์มต้องระบุผู้บังคับบัญชาที่ต้องขออนุมัติ) → กด "ปรับเอกสาร"

ได้ไฟล์ `หนังสือเชิญ-บฑ.31 <รหัสวิชา> <ชื่ออาจารย์>.docx` (และ `หนังสือขออนุมัติ-บฑ.31 …`; ภาษาอังกฤษใช้ `GR.31`) รูปแบบเดียวกับหนังสือจากไฟล์ Export
- อ่านข้อมูล: ชื่อ/ตำแหน่งทางวิชาการ, สถานที่ทำงาน, ผู้บังคับบัญชาที่ต้องขออนุมัติ, หลักสูตร/ภาค (ปกติ/พิเศษ/นานาชาติ),
  รายวิชา, หัวข้อ, วันที่/เวลา/สถานที่สอน, จำนวนนักศึกษา, อาจารย์ผู้รับผิดชอบวิชาและเบอร์โทร
- ผู้ลงนามตั้งค่าได้ที่ `doctypes/bt31/data/signers.json`
- ถ้าสถานที่สอนไม่มีชื่อส่วนงาน โปรแกรมจะเติม "<คณะ/สถาบัน> มหาวิทยาลัยมหิดล" ให้และแจ้งเตือนให้ตรวจสอบ
- รองรับคำร้องทั้ง **ภาษาไทย** และ **ภาษาอังกฤษ** (ดูจากช่อง "ภาษาที่ขอหนังสือเชิญ")
- คำร้องภาษาอังกฤษ: แบบฟอร์มยังมีบางช่องเป็นภาษาไทย (หลักสูตร, ส่วนงาน, ชื่ออาจารย์ผู้รับผิดชอบ ฯลฯ)
  โปรแกรมแปลให้เองเท่าที่ทำได้ (ชื่อส่วนงานของมหิดล, คำนำหน้า/ตำแหน่ง, ชื่อปริญญา) และแสดง **ช่องกรอกภาษาอังกฤษ** ในแถวนั้น
  ช่องที่ยังต้องกรอกจะเป็นสีเหลือง มี * — กรอกครั้งเดียว โปรแกรมจำไว้ใน `doctypes/bt31/data/translations.json` ครั้งต่อไปเติมให้เอง
- วันที่/เวลาภาษาอังกฤษ: `2026/11/12` → `November 12, 2026`, `09.30 am - 12.00 pm` → `09.30 - 12.00`
- ถ้าแบบฟอร์มระบุ "ไม่ต้องขออนุมัติผู้บังคับบัญชา" จะสร้างเฉพาะหนังสือเชิญ
- ประโยค "ทั้งนี้ได้แจ้งให้ผู้บังคับบัญชาของท่านทราบแล้ว" ในหนังสือเชิญภาษาไทย จะมีเฉพาะเมื่อต้องขออนุมัติ
  (ติ๊ก "ต้องการหนังสือขออนุมัติ" และแบบฟอร์มระบุผู้บังคับบัญชา) — ใช้กับไฟล์ Export ด้วย
  (บรรทัดคำสั่ง: `--no-supervisor`)
- บรรทัดคำสั่ง: `python bt31.py "<ไฟล์>.pdf" --approve --pdf` (เพิ่ม `--show` เพื่อดูข้อมูลที่อ่านได้)
  คำร้องภาษาอังกฤษ: เพิ่ม `--en "program=Master of Science Program in ..." --en "contact=Lecturer Dr. ..."`

## หนังสือภาษาอังกฤษ

จัดรูปแบบตามไฟล์ตัวอย่าง (EN): TH Sarabun New 16pt, "Mahidol University" กึ่งกลาง, ตาราง COURSE / TOPIC / DATE / TIME / PLACE
และแก้ตัวพิมพ์ที่ระบบสร้างผิด เช่น "Master Of Science Program In" → "Master of Science Program in",
"FACULTY OF SCIENCE" → "Faculty of Science", "DR." → "Dr.", "M.d." → "M.D.", ตัด "Other" หน้าคำนำหน้าชื่อ,
ลบช่องว่างก่อนเครื่องหมาย , . และเติมจุดท้ายประโยคที่ระบบตัดบรรทัดไว้

## ไฟล์ในโฟลเดอร์

- `app.py` + `web/index.html` — หน้าโปรแกรม hub (เซิร์ฟเวอร์ในเครื่อง 127.0.0.1 + หน้าเว็บ)
- `core/` — ส่วนกลางที่ทุกประเภทเอกสารใช้ร่วมกัน (อ่านไฟล์, สร้าง Word HTML, แปลงด้วย Word)
- `doctypes/` — ประเภทเอกสาร หนึ่งโฟลเดอร์ต่อหนึ่งประเภท
  - `doctypes/bt31/` — บฑ.31: `export.py` (ไฟล์ Export), `eform.py` (PDF บฑ.31), `letter.py` / `layout.py` (กฎและรูปแบบ)
  - `doctypes/bt31/data/signers.json` — ผู้ลงนามในหนังสือที่สร้างจาก บฑ.31 (ไทย `th` / อังกฤษ `en`)
  - `doctypes/bt31/data/courses.json` — รายชื่อวิชา รหัส → ชื่อภาษาอังกฤษ
  - `doctypes/bt31/data/translations.json` — คำแปลภาษาอังกฤษที่เคยกรอก (สร้างอัตโนมัติ)
  - `doctypes/_template/` — แม่แบบสำหรับเพิ่มประเภทใหม่
- `tools/learn.py` — วัดรูปแบบจากไฟล์ตัวอย่าง / เทียบผลลัพธ์กับตัวอย่าง (ใช้ตอนเพิ่มประเภทใหม่)
- `fix_letters.py`, `bt31.py` — บรรทัดคำสั่งของบฑ.31 (คงไว้ให้คำสั่งเดิมใช้ได้)
- `app_classic.py` — หน้าโปรแกรมแบบเดิม (tkinter) สำรองไว้ ใช้ได้โดยไม่ต้องมี Edge (เฉพาะไฟล์ Export บฑ.31)
- `ระบบปรับเอกสาร` (shortcut ไอคอนโปรแกรม) — ดับเบิลคลิกเพื่อเปิดโปรแกรม (ตัวเดียวกับไอคอนบน Desktop)
- `ปรับเอกสาร.bat` — ตัวเปิดสำรอง (ไม่ต้องใช้แล้ว)
- `settings.json` — ค่าตัวเลือกที่จำไว้
- `assets/` — ส่วนหัว Word, สคริปต์แปลงไฟล์ (`to_docx.ps1`), โลโก้, ไอคอนโปรแกรม (`app.ico` สร้างจาก `make_icon.py`), ไฟล์ตัวอย่างอ้างอิง

ต้องใช้ Python 3 และ Microsoft Word (ติดตั้งในเครื่องแล้ว)
